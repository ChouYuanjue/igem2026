# BRIDGE 方法

## 1. 任务与候选空间

BRIDGE（Broad Retrieval with Inference-Driven Gated Experts）根据酶与反应的生化证据排序实验候选。给定反应 \(r\)，R2E 在 **185,918 个蛋白**中检索催化酶；给定蛋白 \(e\)，E2R 在 **11,081 个反应**中检索可能催化的反应。两方向共享基础表示及催化关系图，专家的适用性和排序权限由查询决定。

基础编码器分别映射酶序列与反应转化特征，得到可比较的向量。Broad Retrieval 对完整候选全集计算相似度并建立初始排名，候选未获得专项证据时保留该基础分数。模型将未注释关系视为未知关系，避免假定所有未收录酶–反应配对均为阴性。

## 2. 查询条件专家

令 \(S_0(q,c)\) 表示 Broad 基础得分，\(\Delta_k(q,c)\) 为第 \(k\) 种生化证据在查询 \(q\)、候选 \(c\) 上的归一化修正，\(g_k(q)\) 为其查询条件权限。融合评分为

\[
S(q,c)=S_0(q,c)+\sum_{k}g_k(q)\,\Delta_k(q,c).
\]

当证据不适用、缺失或权限为零时，该专家的贡献恰为零。专家修正作用于指定候选前缀或局部候选范围，保留完整候选池的召回能力。

- **功能证据**：EnzGFM 提供酶与反应的功能相容表示，R2E 使用经过统一验证集校准的 \(1.25w_F(q)\) 作为功能证据强度。
- **结构和机制证据**：CLIPZyme、反应中心表征和有结构支持时的口袋相互作用，对候选集合施加受限修正。
- **长期催化关系证据**：clean2023 训练图中的已确认酶–反应配对提供可追溯的催化邻域。关系缺失的候选仍可接受其他专家排序。
- **家族与领域证据**：P450、磷酸酶、萜类 CAGE 及 TPS 专家按照生化家族、适用性和证据覆盖决定是否参与。
- **情景记忆**：用户确认的新增催化关系作为临时正例支持，仅对当前查询建立一次查询条件更新；无需写入长期图。

## 3. 双侧关系证据与缺失保护

训练图包含 **218,537 条已确认催化关系**。R2E 使用反应端的已记录蛋白邻域和蛋白端的反应上下文，经可见性掩码分别归一化并合并。权限模型利用邻域规模、一致性、关系覆盖及与 Broad 头部排序的相符程度，估计

\[
\alpha(q)=p_{\mathrm{help}}(q)^{\gamma}s(q),
\]

其中 \(p_{\mathrm{help}}(q)\) 表示关系证据改善当前排序的准入概率，\(s(q)\) 表示准入后的条件强度。训练图节点度数反映已收录关系的数量，可能同时受实验研究密度影响，因此关系专家使用查询条件门控。

E2R 对 Broad 空间中的 **16 个已注释近邻蛋白**汇集其真实催化关联；并用 **8 个反应近邻原型**传播结构与转化邻近性。两个归纳项的非负系数分别为 **0.3092** 和 **0.8209**。当前 E2R 查询路由还综合功能、结构与机制证据，在 Broad 的前 **1,000** 名内完成有界精排，其余候选保留可达的基础顺序。

## 4. 运行时情景支持

给定同一查询新增的已确认正例集合 \(S_q\)，根据冻结 Broad 表示计算查询到各支持实体的注意力权重，形成查询相关的临时支持表示。情景更新的权限 \(g_{\mathrm{episode}}(q,S_q)\) 在零到一之间，由支持数、支持一致性和排序证据等特征决定。已存在于 clean2023 的关系只参与长期关系图，用户提供的未收录正例才进入情景支持。支持实体不改变部署候选全集，缺乏支持时该更新严格静音。

## 5. 数据协议与评测

统一训练、验证、测试协议以酶–反应的精确关联为基本监督单元。

| 集合 | 正关联 | 用途 |
| --- | ---: | --- |
| 训练集 | **218,537** | clean2023；基础表征与只读催化关系图 |
| 统一验证集 | **5,216** | 两方向关系门控、功能强度与运行时情景记忆拟合；按查询交叉验证 |
| 正式测试集 | **21,505** | 两方向共用训练期未见关联，完整候选全集排序 |

统一验证集包含 **3,454 个蛋白查询、990 个反应查询**；与测试集精确关联零交集、蛋白查询零交集，其中 **516 个反应查询实体**同时出现在验证集和测试集。R2E 关系门控在 990 个反应查询上进行五折验证；情景记忆从同一验证集内构造多正例支持与剩余目标，分别形成 **535 个 R2E** 与 **766 个 E2R** 有效少样本查询并进行五折验证。

Direct 对每条测试关系等权平均。Balanced 先对 both-seen、protein-cold、reaction-cold、double-cold 四类新颖度等权，再对类别内训练图 degree 层等权；两者均报告原始 MRR、Hit@3、Hit@10、Hit@100。推理排除训练图已知正例，逐关系过滤其他已标注目标。统一数值与四项专家消融见评测报告 docs/evaluation.md。

此次模型校准是在先前已查看正式测试结果后完成的探索性迭代，现有正式测试数值属于**探索性复评**。独立泛化能力需要尚未参与选择过程的新增催化关联确认。

## 6. 解释范围与可复现性

专家分数代表候选检索优先级，不对应绝对酶活、转化率或动力学常数。关系证据仅传播已确认催化关联及明确的归纳邻近性，训练图不存在的关系保持未标注状态。采用正例–未标注关联学习与度数偏差分析的相关方法可参考 [PULL（AAAI 2025）](https://ojs.aaai.org/index.php/AAAI/article/view/33966) 与 [Aiyappa 等（ICML 2025）](https://proceedings.mlr.press/v267/aiyappa25a.html)。

训练–验证–测试样本哈希、两方向门控文件、五折验证及完整消融记录分别保存在 reproducibility/bime_rank/records/BRIDGE_COMMON_5216_VALIDATION_RESULT.json、reproducibility/bime_rank/records/BRIDGE_CANONICAL_21505_RESULT.json 与复现说明 docs/reproducibility.md 中。
