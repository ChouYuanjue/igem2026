# BRIDGE 评测说明

## 1. 评测原则

BRIDGE 不用单一指标概括所有能力。当前评测至少区分：

- 数据库内补全；
- reaction-cold；
- protein-cold；
- double-cold；
- 时间外推；
- broad full-candidate；
- few-shot / seed context；
- 家族专项测试。

比较必须固定候选宇宙、标签边界和切分协议。外部测试只用于确认或否决，不参与回头调参。

## 2. Broad 与完整系统

固定七类综合测试包含 6,554 个唯一查询、11,501 个 query-cell 实例。冻结记录显示：

| 系统 | MRR | Hit@10 | Hit@100 | Hit@1000 |
| --- | ---: | ---: | ---: | ---: |
| Broad Core | 0.2093 | 36.87% | 59.41% | 77.91% |
| BRIDGE 完整系统 | 0.2369 | 41.54% | 64.92% | 77.91% |

解释：专家提升头部排序，Broad 负责总体候选覆盖。

## 3. 专家大类消融

固定七类测试中的大类消融：

| 系统 | MRR | Hit@10 |
| --- | ---: | ---: |
| 完整系统 | 0.236857 | 41.544% |
| 去除功能/同源证据 | 0.226637 | 39.692% |
| 去除结构/机制证据 | 0.224096 | 39.388% |
| 去除专项专家 | 0.236846 | 41.527% |

专项专家只在少量查询激活，因此全局平均增量很小；其价值由匹配领域的独立测试判断。

## 4. 前两类专家的组内消融

固定七类综合测试，保留全部 Family/TPS 专项专家，冻结现有 router，不重训、不重新选择阈值：

| 组别 | 移除成员 | MRR | Hit@10 | Hit@100 | 相对完整系统 |
| --- | --- | ---: | ---: | ---: | --- |
| 功能/同源 | EnzGFM | 0.226637 | 39.692% | 62.664% | MRR −0.010220；Hit@10 −1.852 pp |
| 功能/同源 | seed context | 0.236857 | 41.544% | 64.925% | 0 |
| 功能/同源 | homology context | 0.236857 | 41.544% | 64.925% | 0 |
| 结构/机制 | CLIPZyme | 0.233730 | 40.631% | 64.151% | MRR −0.003126；Hit@10 −0.913 pp |
| 结构/机制 | reaction-center | 0.234318 | 41.414% | 65.116% | MRR −0.002538；Hit@10 −0.130 pp |
| 结构/机制 | 结构支持信号 | 0.237564 | 41.666% | 65.247% | 移除后略升：MRR +0.000707；Hit@10 +0.122 pp |

seed context 与 homology context 只有在查询提供对应上下文时才激活；固定七类测试没有提供这类上下文，因此总体消融为 0。结构支持信号在本协议中实际指进入 router 的 cached pocket-support 特征；whole-structure support 不直接参与这一冻结七类打分。当前结果说明结构/机制组的主要正贡献来自 CLIPZyme 与 reaction-center，结构支持门控在综合测试上略有负贡献。

## 5. CAGE 分层比较

七类统一比较：

| 方法 | MRR | Hit@10 | Hit@100 |
| --- | ---: | ---: | ---: |
| 原始 CAGE | 0.100763 | 20.53% | 27.56% |
| Broad Top-1000 + 通用 CAGE | 0.025714 | 5.44% | 18.76% |
| BRIDGE | 0.236857 | 41.54% | 64.92% |

Broad Top-1000 的阳性 query coverage 约 77.91%，通用 CAGE 可评分阳性 query coverage 约 25.08%。因此“先用 Broad 扩池，再把所有候选交给同一个结构模型”不能解决广域排序。

## 6. 家族专项专家

冻结专项测试中，family-tuned CAGE 相比 generic CAGE：

- P450：MRR 约 0.0370 → 0.0705；
- phosphatase：MRR 约 0.2522 → 0.3169；
- terpene：MRR 约 0.0189 → 0.0387。

这些结果用于证明局部能力，不用于把专项专家推广成通用排序器。

## 7. 历史证据

当前 BRIDGE 数值由 `reproducibility/bridge/canonical.json` 指向冻结结果。部分源文件仍使用迁移前的 `BRIDGE_*` 名称；这些文件保持原名以保留来源、路径和哈希连续性。
