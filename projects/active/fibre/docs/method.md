# FIBRE 方法

这份文档只描述当前已经实现并经过评测的模型与数学对象。

## 1. 输入与开放评分

反应侧冻结入口为 8270 维多视图表示，包含整体反应指纹、底物/产物分子指纹、有符号变化、分子描述量和类别信息。

蛋白侧冻结入口为由氨基酸序列得到的 1152 维表示。

模型评分依赖两侧编码结果，不依赖训练实体编号。能够经过相同编码函数的新反应和新蛋白都能进入同一个评分函数。

## 2. 一个通用分量与八个局部模式

FIBRE-Modes 冻结模型包含：

- 一个 128 维通用交互分量；
- 八个 32 维局部模式分量。

总空间写成

\[
\mathcal H
=
\mathcal H_0
\oplus
\mathcal H_1
\oplus\cdots\oplus
\mathcal H_8.
\]

每个分量产生配对分数

\[
s_k(r,e)=\langle x_k(r),y_k(e)\rangle.
\]

八个局部分量没有固定生化机制名称，当前只作为潜在条件模式使用。

## 3. 异维空间之间的有限秩算子

设反应和蛋白隐藏表示分别为

\[
h_R(r)\in\mathbb R^{d_R},
\qquad
h_E(e)\in\mathbb R^{d_E}.
\]

第 \(k\) 个模式分别使用

\[
P_k^R\in\mathbb R^{m_k\times d_R},
\qquad
P_k^E\in\mathbb R^{m_k\times d_E}
\]

进入同一个局部空间。忽略单位化时，

\[
s_k(r,e)
=
h_R(r)^\top
A_k
h_E(e),
\qquad
A_k=(P_k^R)^\top P_k^E,
\]

并且

\[
\operatorname{rank}(A_k)\le m_k.
\]

该等价关系及异维支持已经由自动测试固定。

## 4. 双方向条件读出

反应找酶：

\[
S_{R\to E}(r,e)
=
(1-\mu_R)s_0(r,e)
+
\mu_R
\sum_{k=1}^{8}
q^R_k(r)s_k(r,e).
\]

酶找反应：

\[
S_{E\to R}(r,e)
=
(1-\mu_E)s_0(r,e)
+
\mu_E
\sum_{k=1}^{8}
q^E_k(e)s_k(r,e).
\]

两方向共享九组配对分数，查询侧不同，因此门控不同。

对应的块对角条件算子写成

\[
M_R(r)
=
\operatorname{diag}
\left(
(1-\mu_R)I_{128},
\mu_Rq^R_1I_{32},
\ldots,
\mu_Rq^R_8I_{32}
\right),
\]

并满足

\[
S_{R\to E}(r,e)
=
\langle X(r),M_R(r)Y(e)\rangle.
\]

仓库测试已经验证条件算子形式与真实评分实现等价。

## 5. 训练目标

主训练信号为双向多阳性对比排序。

对一个查询，阳性集合为 \(P\)，有效分母为 \(D\)，分数为 \(z_j\)：

\[
\mathcal L_{\mathrm{rank}}
=
\log\sum_{j\in D}e^{z_j}
-
\log\sum_{i\in P}e^{z_i}.
\]

实验预算对应的前若干名边界损失为

\[
\mathcal L_K
=
\operatorname{softplus}
\left(
z^-_{(K)}-z^+_{\max}+m
\right),
\]

当前使用 \(K=3,10,20\)。

训练还保留：

- 门控均衡；
- 门控熵；
- 专家多样性。

FIBRE-Modes 删除了 FIBRE-Atlas 的跨专家分数一致性惩罚。

## 6. 查询级加法不变量

对任意固定查询，如果给全部候选分数加同一个常数

\[
z'_j=z_j+c,
\]

则多阳性对比损失与前若干名边界损失都保持不变。

这一性质已经由自动测试验证。相同测试也确认整体缩放会改变对比损失。

因此当前监督直接约束查询内部相对顺序。

## 7. 模式置换不变量

若同时置换八个局部模式分数和门控坐标，

\[
s_k\mapsto s_{\pi(k)},
\qquad
q_k\mapsto q_{\pi(k)},
\]

则总评分保持不变。

仓库已经测试：

- 方向评分在统一模式置换下不变；
- 模式分歧在统一模式置换下不变。

所以当前模式编号只在置换等价意义下有定义。

## 8. 专家分歧

局部模式均值：

\[
\bar s_q
=
\sum_kq_ks_k.
\]

局部模式方差：

\[
V_q
=
\sum_kq_k(s_k-\bar s_q)^2.
\]

加入通用分量后的完整方差：

\[
V_{\mathrm{full}}
=
\mu V_q
+
\mu(1-\mu)(\bar s_q-s_0)^2.
\]

仓库已经实现并测试这条全方差分解。

FIBRE-Modes 冻结排序不使用该方差重排候选。

## 9. 模式概率更新原语

对模式先验 \(q^-\) 和已经由具体证据模型产生的无量纲对数证据 \(\ell\)，更新为

\[
q^+
=
\arg\max_{q\in\Delta}
\left[
\sum_kq_k\ell_k
-
D_{\mathrm{KL}}(q\Vert q^-)
\right],
\]

闭式解：

\[
q_k^+
=
\frac{
q_k^-e^{\ell_k}
}{
\sum_jq_j^-e^{\ell_j}
}.
\]

仓库已经验证：

- 零证据恒等回退；
- 多次证据按对数增量可组合；
- 权重始终非负并归一；
- 指数更新在零证据强度处的导数等于费舍尔–拉奥自然梯度；
- 模式信息增益 \(D_{\mathrm{KL}}(q^+\Vert q^-)\) 对统一模式置换不变。

这些原语位于：

`projects/active/fibre/kernel/mode_geometry.py`

## 10. 反应中心模式证据实验

已经完成一个实际的两阶段反应中心实验：

1. 训练 FIBRE-Modes 基础八模式；
2. 冻结基础模型全部参数；
3. 反应中心特征进入零初始化、无偏置的八维证据头；
4. 证据只更新反应找酶方向的模式门控；
5. 酶找反应评分路径保持不变。

更新式为

\[
q_k^{R,+}(r)
\propto
q_k^{R,-}(r)
\exp\bigl(\ell_k^{RC}(r)\bigr).
\]

开发九格：

- 反应找酶平均倒数排名：0.05165 → 0.05252；
- 前五、前十、前二十保持；
- 前三：4.94% → 4.53%；
- 中位最佳阳性名次：140 → 146。

冻结十六格：

- 酶找反应全部指标与 FIBRE-Modes 基线逐位一致；
- 反应找酶平均倒数排名：0.04246 → 0.04179；
- 前三、前五保持；
- 前十：11.46% → 11.04%；
- 前二十：19.75% → 19.32%；
- 中位名次：135 → 136。

该候选没有晋级。FIBRE-Modes 冻结模型不使用反应中心证据头。

## 11. FIBRE-Modes 选择结果

删除跨专家一致性项的候选在九个开发格选定，十六个冻结格只查看一次。

冻结确认中：

- 酶找反应平均倒数排名：0.08002 → 0.08080；
- 反应找酶平均倒数排名：0.04212 → 0.04246；
- 反应找酶前五、前十、前二十提高；
- 酶找反应前十、前二十分别下降约 0.23 和 0.12 个百分点。

成对自助法的大多数差异区间跨零，因此 FIBRE-Modes 的结论限定为结构简化并保持同层级性能。

## 13. 当前边界

FIBRE-Modes 没有使用或输出：

- 激活自由能；
- 速率常数；
- 催化常数；
- 米氏常数；
- 热力学温度；
- 焦耳每摩尔或千焦每摩尔数值。

此前完成的对数指数和与二阶累积量实验只属于现有无量纲分数的非线性聚合探针，均未晋级，因此不进入 FIBRE-Modes 方法定义。

## 14. 科学证据扩展层

FIBRE-Modes 的八个潜在催化模式属于核心模型内部表示。结构、反应中心、另一种分子表示以及用户已知阳性等外部信息通过冻结核心排序上的科学证据层接入。

设冻结核心对查询 \(q\) 和候选 \(c\) 的分数为 \(S_0(q,c)\)，第 \(j\) 条已经准入的证据经查询内校准后为 \(E_j(q,c)\)，则

\[
S(q,c)
=
S_0(q,c)
+
\sum_j \alpha_j E_j(q,c),
\qquad
\alpha_j\ge 0.
\]

核心系数固定为 1。每条证据独立声明可用性；缺失时该项贡献严格为 0。若存在经过验证的质量量 \(Q_j\in[0,1]\)，证据可靠度可以写成

\[
\alpha_j+\beta_jQ_j,
\qquad
\alpha_j,\beta_j\ge0.
\]

新证据的参数只用内部训练外分数和显式阳性/阴性结果，通过非负成对逻辑排序目标拟合。当前已经验证三种性质不同的证据：

- CLIPZyme 结构证据：内部三折 MRR 0.09868 → 0.11487；系数冻结后，Rhea128→141 严格双冷 R2E 的 MRR 0.03626 → 0.06204；
- 已知阳性上下文：2,595 次内部交叉拟合试验中 MRR 0.13137 → 0.29881；
- 反应中心机制证据：3,299 个 held-out 查询的三个折中成对逻辑损失均下降，最终基础强度 0.21333，RXNMapper 质量斜率 0.11159。

三类结果来自不同实验协议和核心分数来源，因此这里验证的是统一证据接口对三类信息都成立。它们没有在同一核心、同一查询集合上联合拟合。两个以上证据同时进入同一排序时，当前实现要求联合交叉拟合非负系数，并将结果绑定到同一个冻结核心 baseline；多个独立准入结果不能直接相加。联合拟合默认使用 L1 正则，使复制同一证据不会仅因拆成多个模块而降低正则代价。

正式准入还检查查询级稳定性。除每个 held-out 折的成对逻辑损失都要下降外，全部 OOF 查询的平均增益在确定性 bootstrap 下也必须得到正的 95% 下界。反应中心机制证据按这一更严格规则重放后，3,299 个查询的平均增益为 0.02167，95% 区间为 [0.01657, 0.02673]，仍通过准入。

广域分量与局部模式之间的总质量也做过查询自适应实验。双向端到端版本在开发区提高 E2R 的同时明显损害 R2E；只让 E2R 端到端自适应仍因共享主干训练造成 R2E 回退。最后冻结完整 v2 核心，只训练 513 参数的蛋白侧 E2R 总质量门，R2E 由结构保证不受该门影响。冻结 16 格中 E2R MRR 从 0.08080 到 0.08120，Hit@3/5/10 各提高约 0.23 个百分点，Hit@20 不变；主要差异的成对 bootstrap 区间跨零，最佳阳性中位名次从 56 到 57。该结构未进入当前 FIBRE-Modes，当前 \(\mu_R,\mu_E\) 仍为两个方向各自学习的标量。

候选生成和实验约束与催化证据分开。能够发现新候选的模块可以同时声明候选生成能力；宿主、库存、表达性和实验成本进入实验决策层。
