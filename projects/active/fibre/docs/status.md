# FIBRE 当前状态

当前冻结模型采用第二版条件模式读出。这个状态页只列已经实现并完成评测的事实。

## 当前计算图

模型包含一个 128 维通用交互分量和八个 32 维局部模式分量。

反应找酶：

\[
S_{R\to E}
=
(1-\mu_R)s_0
+
\mu_R
\sum_{k=1}^{8}
q^R_k(r)s_k.
\]

酶找反应：

\[
S_{E\to R}
=
(1-\mu_E)s_0
+
\mu_E
\sum_{k=1}^{8}
q^E_k(e)s_k.
\]

第二版保持第一版输入、网络宽度、八专家结构、双向多阳性排序目标和前三/前十/前二十边界目标，只删除跨专家分数一致性惩罚。

## 第二版选择结果

九个开发格中，删除跨专家一致性惩罚后：

- 反应找酶平均倒数排名：0.05027 → 0.05165；
- 反应找酶前三：4.12% → 4.94%；
- 反应找酶前十：保持 9.88%；
- 反应找酶前二十：18.11% → 18.52%。

十六个冻结格一次性确认中：

- 酶找反应平均倒数排名：0.08002 → 0.08080；
- 反应找酶平均倒数排名：0.04212 → 0.04246；
- 反应找酶前五、前十、前二十均提高；
- 酶找反应前十、前二十分别下降约 0.23、0.12 个百分点。

成对查询格自助法的大多数差异区间跨零，所以当前结论限定为：删除一个额外经验约束以后，模型结构更简单，整体性能保持同层级。

## 反应中心模式证据实验

已经完成一个两阶段实验：

1. 训练第二版基础模型；
2. 冻结基础参数；
3. 反应中心特征训练零初始化、无偏置的八维证据头；
4. 只修改反应找酶方向的模式权重；
5. 酶找反应路径保持不变。

开发九格：

- 反应找酶平均倒数排名：0.05165 → 0.05252；
- 前五、前十、前二十保持；
- 前三：4.94% → 4.53%。

冻结十六格：

- 酶找反应全部指标逐位不变；
- 反应找酶平均倒数排名：0.04246 → 0.04179；
- 前三、前五保持；
- 前十、前二十各下降约 0.42 个百分点。

该候选没有晋级。当前冻结评分不使用反应中心证据头。

## 非线性聚合探针

对现有无量纲专家分数做过两类非线性聚合实验：

- 加权对数指数和；
- 线性均值加二分之一加权方差。

两者都没有通过晋级纪律。前者在一次冻结确认中回退；后者在开发格已经否决。

这些结果只作为已完成的负实验保留，不构成当前模型定义。
