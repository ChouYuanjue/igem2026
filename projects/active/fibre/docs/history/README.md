# 研发历史文档说明

本目录保留两种用途不同的历史材料。

`SCIENTIFIC_NARRATIVE_HISTORY_ZH.md` 面向比赛页面、答辩、论文式介绍和团队统一口径。它沿着“有限实验预算—大规模排序—开放输入—多表征条件性—受约束多专家—关系理论探索—催化相容核”的因果链组织，只保留会改变读者理解和后续设计的关键实验。

`RAW_DEVELOPMENT_HISTORY_ZH.md` 面向内部复盘和追溯。正文仍按研究问题和因果关系连续书写，文末史料注释负责提交编号、冻结记录和文件路径；细小尝试放在覆盖索引中，避免干扰正文阅读。

数据库专项暂不在这两份文档中独立重建。人类实践相关内容只使用已知的团队事实：外部真实用户试用先推动语义路由和科研入口，技术模型的演进仍由模型实验与数学问题支撑。
