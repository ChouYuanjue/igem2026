# FIBRE history documents

This directory contains two deliberately different views of the same research history.

## `SCIENTIFIC_NARRATIVE_HISTORY_ZH.md`

Use this first when preparing a competition page, presentation, paper-style overview or team-wide story. It compresses the project into the major scientific causal chain: early structure/CAGE retrieval failure -> TPS open-world retrieval -> real-user/HP-driven routing and Agent evolution -> broad BiME-Rank -> product-manifold intermediate theory -> final FIBRE interaction atlas.

It preserves negative results and validation boundaries, but only promotes experiments that materially changed the scientific argument.

## `RAW_DEVELOPMENT_HISTORY_ZH.md`

This is the high-density research archive. "Raw" does **not** mean a flat commit dump. The document groups work by research question, hypothesis family and decision, while its appendices retain commit/result/config/script traceability so small attempts are not silently lost.

Use it when checking exact experiment lineage, rejected approaches, superseded geometry, evaluation-policy changes or the origin of a claim in the narrative document.

## `CLAIM_EVIDENCE_LEDGER_ZH.md`

Use this while drafting claims. It separates mathematical propositions, implemented mechanisms, frozen empirical results, historical evidence, product capabilities, Human-Practices facts and future extensions, and records the most important overclaim boundaries.

## Scope boundary

These histories cover the model/retrieval/Agent/evaluation lines that were audited against the repository. The database project is intentionally not reconstructed as a standalone storyline here; database facts appear only where they form an explicit interface or evidence boundary for the modeled workflow.

Human-Practices statements are treated as team-provided facts unless a primary interview record is present in the audited repository. The documents therefore preserve the verified chronology that external user testing preceded the formal Agent harness, but do not invent interviewees or quotations.
