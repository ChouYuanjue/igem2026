# FIBRE 评测约定

这份文档只描述已经执行的评测规则和已经存在的证据面。

## 1. 基准与应用分离

只有冻结复现配置支撑模型性能结论。应用侧使用的额外候选库、结构资产或上下文信息不能回流到冻结基准中的模型选择。

FIBRE-Modes 配置：

`reproducibility/bime_rank/configs/fibre_conditional_modes_v2.yaml`

FIBRE-Modes 记分卡：

`reproducibility/bime_rank/records/FIBRE_CONDITIONAL_MODES_SCORECARD_V2.json`

## 2. 开发选择与冻结确认

FIBRE-Modes 的结构修改只在九个开发格选择。

候选确定以后，十六个冻结格只查看一次。冻结结果揭示以后没有继续针对这些结果调参。

成对自助法承担不确定性描述。当前差异的大多数区间跨零，因此 FIBRE-Modes 只报告结构简化和性能保持，不把小数值差异写成显著优势。

## 3. 已执行的主要评测面

### 熟悉协议

用于测量已有萜类合酶任务分布上的早期排序能力。

### 25 格严格双冷启动

每个测试格同时留出蛋白簇和反应簇。两个方向分别报告。

### 185,918 蛋白广域检索

固定严格萜类合酶反应查询，把候选扩展到 185,918 条蛋白。完整条件模式与同一训练模型的通用分量消融直接比较。

### 严格时间评测

用于检查训练时间之后的新对象与新关系迁移。该证据来自冻结的 BiME-Rank 通用路线，与 FIBRE-Modes 的萜类合酶结果分开报告。

### 外部同支持比较

固定酶集和孤儿反应比较锁定双方共同支持的查询与候选范围。

## 4. 指标

每个排名任务至少报告：

- 最佳阳性的精确名次；
- 平均倒数排名；
- 前三、前五、前十、前二十命中；
- 多阳性任务中的命中数与阳性召回；
- 已有记录需要时报告平均准确率、折损累计增益和宏观曲线面积。

任何方法升级都保留下降指标。

## 5. FIBRE 两版同模型结构比较

已经执行的核心同模型消融包括：

- 完整九分量读出；
- 只保留通用分量；
- FIBRE-Atlas 一致性权重 0.02；
- FIBRE-Modes 一致性权重 0。

输入、网络宽度、随机种子和训练协议保持一致。

开发阶段还执行过：

- 条件概率混合；
- 按专家维度缩放的一致性；
- 加权对数指数和聚合；
- 线性均值加二分之一加权方差。

前两类未获得结构与性能上的晋级依据。加权对数指数和在一次冻结确认中两方向平均倒数排名回退；二阶聚合在开发格直接否决。它们只作为负实验记录保存。

## 6. 反应中心模式证据评测

已经执行一个两阶段反应中心实验。

基础 FIBRE-Modes 训练结束后冻结。反应中心只训练八维证据头，并只修改反应找酶方向的模式权重；酶找反应路径保持不变。

开发九格：

- 反应找酶平均倒数排名 0.05165 → 0.05252；
- 前五、前十、前二十保持；
- 前三 4.94% → 4.53%。

冻结十六格：

- 酶找反应全部指标与基线逐位一致；
- 反应找酶平均倒数排名 0.04246 → 0.04179；
- 前三、前五保持；
- 前十、前二十各下降约 0.42 个百分点。

该候选没有晋级。

## 7. 专家分歧与排名稳定度

专家分歧量

\[
U
=
\sum_kq_k(s_k-\bar s)^2
\]

只作为描述性诊断。当前评测不依据该量重排候选，也不把它解释成实验成功概率。

排名稳定度使用重复评分样本计算：

\[
C_i^{(K)}
=
\Pr[R_i\le K],
\]

\[
D_{ij}
=
\Pr[S_i>S_j],
\]

以及候选名次分位区间。

这些量只描述重复评分下的排序稳定性。

## 8. 候选完整性

局部信息缺失不能从基础候选宇宙中删除候选。

FIBRE-Modes 冻结模型只使用统一基础反应输入和蛋白序列输入。结构、口袋、反应中心等历史信息源没有被写成冻结八模式的显式组成。

## 9. 科学证据扩展层

新科学证据先在冻结核心排序之外独立准入。准入只使用训练外或交叉拟合分数、显式阳性/阴性结果和非负成对逻辑排序目标。每个查询在成对损失中拥有相同总权重。

当前三类验证分别承担不同证据等级：

- CLIPZyme 结构证据完成三折内部拟合后固定系数，并在 Rhea128→141 的 144×166,202 严格双冷 R2E 支持上确认一次；
- 已知阳性上下文在 2,595 次内部交叉拟合试验中验证；
- 反应中心机制证据在 3,299 个 clean2023 held-out 查询上完成三折准入，三个留出折的成对逻辑损失均下降。

证据表中的 `available=false` 表示真正缺失，该候选得到零证据贡献。可选 `quality` 只有在存在明确、可验证含义时参与可靠度拟合。候选生成能力与排序证据分别记录。

统一结果：

`reproducibility/bime_rank/records/FIBRE_SCIENTIFIC_EVIDENCE_V1_RESULT.json`

## 10. 湿实验边界

早期萜类合酶候选进入过真实湿实验工作流，这一事实只支撑真实使用场景和候选生成需求。

后期 131,532 条私有序列任务证明系统可以从研究者自有序列库生成候选优先级；对应那一批反应没有完成相应湿实验，因此不作为前瞻实验验证。

FIBRE-Modes 的性能结论来自自身冻结计算评测；BiME-Rank 的通用严格时间、外部同支持和上下文结果作为前代广域能力基线单独报告。

## 11. 当前不评测的量

当前评测没有：

- 真实动力学常数误差；
- 激活自由能误差；
- 催化常数误差；
- 米氏常数误差；
- 热力学量误差。

这些量没有进入当前训练目标，也没有被当前模型输出。
