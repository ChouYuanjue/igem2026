\chapter*{前言：本书证明什么，也不证明什么}
\addcontentsline{toc}{chapter}{前言：本书证明什么，也不证明什么}

FIBRE（\textbf{Factorized Interaction Basis for Reaction--Enzyme}）的最终数学对象是一个\textbf{交互图册（interaction atlas）}。本书只讨论这一模型及其必要的历史推导，不讨论 Agent、数据库或比赛叙事。

全书最重要的边界有三条。

\begin{enumerate}
  \item 我们不把当前模型分数解释成“酶在任何条件下是否催化某反应”的物理真值。真实活性依赖实验和细胞环境；当前模型学习的是在声明任务和观测语义下的\textbf{工作催化相容性（working catalytic compatibility）}。
  \item 我们不声称当前冻结实现的 R2E 与 E2R 最终分数逐点相同。两个方向共享局部 pair interaction，但使用不同的方向化 partition/readout。
  \item 我们只把已经落到 kernel、训练器或冻结 evaluator 的性质称为“实现”；纯数学上自然的扩展会明确标注为扩展或未来工作。
\end{enumerate}

数学的用途不是为已有代码增加装饰，而是给每个关键设计回答一个可验证的问题：为什么不同维度的 representation 可以共存？为什么 missing structure 不等于 negative？为什么旧 multi-expert 可以被严格重写成 partition of unity？为什么方向化 readout 仍可共享一个 scientific target？为什么新实验能以有限秩方式更新 interaction 而不重训 encoder？这些问题分别对应后文的命题和证明。

\chapter{从生物活性到任务层催化相容性}

\section{真正的物理对象包含条件}

令 $r\in\Rset$ 表示一个有效化学转化，$e\in\Eset$ 表示一个有效酶分子输入，$c\in\Cset$ 表示 assay、细胞或环境条件。概念上更完整的生物学响应是
\begin{equation}
A:\Rset\times\Eset\times\Cset\to\mathbb R,
\qquad A(r,e;c).
\end{equation}
其中 $c$ 可以包含 pH、温度、辅因子、底物浓度、表达宿主、检测 endpoint 等。

现有 enzyme--reaction registry 并不是 $A$ 的稠密张量观测。它通常只告诉我们“这个 pair 曾被支持”，却缺少完整重复条件；显式 inactive assay 更少，而且一个条件下 inactive 不能逻辑推出所有条件下 permanently negative。

\begin{definition}[任务层工作相容性]
在一个声明好的 retrieval population、数据快照与观测语义下，记
\begin{equation}
\Kstar:\Rset\times\Eset\to\mathbb R
\end{equation}
为\textbf{工作催化相容性}。它是从不完整条件观测到 retrieval task 的投影对象，而不是 context-free physical law。
\end{definition}

\begin{remark}
如果未来获得足够密集、可比较的 condition-resolved assays，自然扩展应当重新把 $c$ 纳入 interaction domain，而不是给当前 $\Kstar(r,e)$ 随手加一个 pH bonus。
\end{remark}

\section{统计困难：稀疏、选择性、positive-unlabeled}

当前 general candidate universe 约含 $185{,}918$ 个 proteins 与 $11{,}081$ 个 reactions，潜在笛卡尔 pair 数超过 $2.06\times 10^9$。已记录 association 约 $2.47\times10^5$ 条，机械占比约 $0.012\%$。这个比例\textbf{绝不能}解释为真实活性率；它只说明被记录监督相对组合空间极稀疏。

更重要的是观测并非随机：研究热点、可表达性、历史 assay 技术、物种和工业兴趣都会影响哪个 pair 被测。于是“没有记录”通常应记为 unknown，而不是 negative。

\begin{assumption}[PU 语义]
除非存在明确、与当前 claim scope 相容的 inactive assay，否则未记录 pair 不自动视为生物学负例。
\end{assumption}

\section{为什么 object-side information 仍然有用}

pair label 稀疏并不意味着单个对象不可描述。Reaction 可由 substrate/product、DRFP、RDKit descriptors、atom mapping、changed bonds、reaction center 等观测；enzyme 可由 sequence、protein language model、family、structure、pocket、motif、cofactor 等观测。因此核心建模问题变为：

\begin{quote}
如何利用\textbf{丰富但异质、部分缺失的 object-side observations}，推断\textbf{稀疏、选择性且条件不完整的 pair relation}？
\end{quote}

这正是 interaction atlas 的出发点。

\chapter{多视图观测与交互图册}

\section{可变的观测集合}

对 reaction $r$，记可用 views 为
\begin{equation}
X_R(r)=\{x_R^v(r):v\in V_R(r)\};
\end{equation}
对 enzyme $e$，记
\begin{equation}
X_E(e)=\{x_E^u(e):u\in V_E(e)\}.
\end{equation}
不同对象的 $V_R(r)$、$V_E(e)$ 可以不同。特别地，structure 或 pocket 缺失只意味着某个 coordinate chart 不可用，而不是观测值等于 0。

\section{局部 chart}

\begin{definition}[Interaction chart]
一个局部交互 chart $\alpha\in\Aset$ 由以下元素构成：
\begin{enumerate}
  \item 适用域 $U_\alpha\subseteq\Rset\times\Eset$；
  \item reaction coordinate map $\phia:U_\alpha^R\to H_\alpha^R$；
  \item enzyme coordinate map $\psia:U_\alpha^E\to H_\alpha^E$；
  \item 局部双线性交互算子 $\Ga:H_\alpha^E\to H_\alpha^R$ 的矩阵表示；
  \item 局部 scalar interaction
  \begin{equation}
  \Ka(r,e)=\phia(r)^\top\Ga\psia(e).
  \end{equation}
\end{enumerate}
\end{definition}

$H_\alpha^R$ 与 $H_\alpha^E$ 不要求同维、不要求同语义，也不要求和另一个 chart 的 latent axes 对齐。一个 whole-reaction/sequence chart 可以与 reaction-center/pocket chart 完全使用不同 representation。

\section{Availability 与 applicability 的分离}

定义 availability indicator
\begin{equation}
a_\alpha(r,e)\in\{0,1\},
\end{equation}
表示运行 chart $\alpha$ 所需的输入是否存在。另令 $q_\alpha(r,e)$ 为 applicability logit，表示该 biochemical/information regime 对此 pair 是否有理由发挥作用。工程上最直接的 partition 是 masked softmax：
\begin{equation}
\rho_\alpha(r,e)=
\frac{a_\alpha(r,e)\exp q_\alpha(r,e)}
{\sum_\beta a_\beta(r,e)\exp q_\beta(r,e)}.
\label{eq:masked-softmax}
\end{equation}

\begin{assumption}[Universal chart]
存在一个 raw-input universal chart $U_0=\Rset\times\Eset$，只依赖每个 valid reaction/protein 都具有的基本分子输入，因此对所有 valid pair 有 $a_0(r,e)=1$。
\end{assumption}

这个假设保证 masked partition 的分母永不为空。

\chapter{局部双线性交互的坐标不变性}

“ESM-C 与 EnzGFM 维度不同，所以不能放在同一个数学模型里”是一个常见误解。Interaction atlas 不要求不同 chart 共享坐标，只要求每个 chart 的 scalar interaction 对自身坐标变换保持不变。

\begin{theorem}[局部交互的基变换不变性]
固定一个 chart，采用列向量记号。令
\begin{equation}
K(r,e)=\phi(r)^\top G\psi(e).
\end{equation}
对任意可逆矩阵 $A,B$，作坐标变换
\begin{equation}
\widetilde\phi=A\phi,
\qquad
\widetilde\psi=B\psi,
\end{equation}
并定义
\begin{equation}
\widetilde G=A^{-\top}GB^{-1}.
\end{equation}
则
\begin{equation}
\widetilde\phi^\top\widetilde G\widetilde\psi
=\phi^\top G\psi.
\end{equation}
\end{theorem}

\begin{proof}
直接代入：
\begin{align}
\widetilde\phi^\top\widetilde G\widetilde\psi
&=(A\phi)^\top A^{-\top}GB^{-1}(B\psi)\\
&=\phi^\top A^\top A^{-\top}G B^{-1}B\psi\\
&=\phi^\top G\psi.
\end{align}
\end{proof}

\begin{remark}[与代码 row-vector convention 的对应]
\texttt{bilinear\_chart\_score} 使用 batch row vectors。如果写成 $\phi'=\phi A$、$\psi'=\psi B$，对应变换是 $G'=A^{-1}GB^{-\top}$。仓库测试直接验证了这一等式。
\end{remark}

这一定理的实际意义是：chart 的科学对象是“coordinate + interaction form”这一对，而不是某个 latent axis 本身。不同 encoder 不需要先强行 Procrustes-align 才能属于同一个 interaction-atlas framework。

\chapter{Partition of Unity 与缺失模态的严格语义}

\section{Pair-aware 理想形式}

设 $\Aset(r,e)$ 为 pair 上 available/applicable charts。理想 pair-aware atlas 取
\begin{equation}
\rho_\alpha(r,e)\ge0,
\qquad
\sum_{\alpha\in\Aset(r,e)}\rho_\alpha(r,e)=1,
\end{equation}
并定义
\begin{equation}
\Khat(r,e)=
\sum_{\alpha\in\Aset(r,e)}\rho_\alpha(r,e)\Ka(r,e).
\label{eq:glue}
\end{equation}

\begin{theorem}[Convex-hull bound]
对任意固定 pair，若 partition 非负且和为 1，则
\begin{equation}
\min_{\alpha\in\Aset(r,e)}\Ka(r,e)
\le \Khat(r,e)\le
\max_{\alpha\in\Aset(r,e)}\Ka(r,e).
\end{equation}
\end{theorem}

\begin{proof}
令 $m=\min_\alpha K_\alpha$、$M=\max_\alpha K_\alpha$。因为 $m\le K_\alpha\le M$ 且 $\rho_\alpha\ge0$，
\begin{equation}
m\sum_\alpha\rho_\alpha
\le\sum_\alpha\rho_\alpha K_\alpha
\le M\sum_\alpha\rho_\alpha.
\end{equation}
利用 $\sum\rho_\alpha=1$ 即得。
\end{proof}

\begin{corollary}[Single-chart exact fallback]
若某个 pair 只有 chart $\gamma$ available，则 $\rho_\gamma=1$ 且 $\Khat=K_\gamma$。
\end{corollary}

\begin{proof}
非负且总和为 1 的单元素 partition 唯一为 $\{1\}$。
\end{proof}

\section{Missing-neutrality 比“补零”更强}

\begin{proposition}[Masked softmax 的相对权重保持]
在式 \eqref{eq:masked-softmax} 中，若 chart $k$ 不可用并被移除，则对任意仍可用 $i,j$，
\begin{equation}
\frac{\rho_i}{\rho_j}=\exp(q_i-q_j),
\end{equation}
与被移除 chart 的 logit 无关。
\end{proposition}

\begin{proof}
两权重具有相同归一化分母，直接相除即可。不可用 chart 的 $a_k=0$，不进入分母。
\end{proof}

因此 missing chart 不是“score=0 后参与平均”，而是\textbf{从该 pair 的坐标覆盖中不存在}。这避免了结构缺失被错误解释成催化不相容。

\begin{theorem}[Universal scoreability]
若 universal chart 对每个 valid pair 可用，且每个 available chart 都能产生有限 scalar score，则式 \eqref{eq:glue} 对每个 valid pair 都定义良好。
\end{theorem}

\begin{proof}
Universal chart 保证 available set 非空，因此 partition 可归一化；有限个有限 score 的凸组合仍有限。
\end{proof}

\chapter{旧多专家模型为何是 Atlas 的严格特例}

历史 BiME/multi-expert score 具有形式
\begin{equation}
S=(1-m)K_0+m\sum_{k=1}^{K}g_kK_k,
\qquad
g_k\ge0,\quad\sum_k g_k=1,\quad 0\le m\le1.
\end{equation}

\begin{theorem}[Convex expert mixture 与 partition of unity 的代数等价]
定义
\begin{equation}
\rho_0=1-m,
\qquad
\rho_k=mg_k\quad(k\ge1),
\end{equation}
则 $\rho_k\ge0$、$\sum_{k=0}^{K}\rho_k=1$，且
\begin{equation}
S=\sum_{k=0}^{K}\rho_kK_k.
\end{equation}
\end{theorem}

\begin{proof}
非负性显然。并且
\begin{equation}
\rho_0+\sum_{k=1}^{K}\rho_k
=(1-m)+m\sum_kg_k=(1-m)+m=1.
\end{equation}
代入 score 即得原式。
\end{proof}

这条等价很重要：采用 atlas ontology 不需要为了“数学更漂亮”改变历史 inference numerics。Universal channel 只是在新解释中成为 chart $0$，而不是一个特权模型加若干 residual votes。

\chapter{方向化检索：共享 Interaction，不虚构相同 Readout}

\section{当前冻结 realization}

理想 pair-aware $\rho_\alpha(r,e)$ 不是当前冻结 multi-expert trainer 的逐点实现。当前实现共享 local pair scores $K_\alpha(r,e)$，但两个方向使用不同 query-side partitions：
\begin{equation}
S_d(r,e)=\sum_\alpha \rho_\alpha^{(d)}(r,e)K_\alpha(r,e),
\qquad d\in\{\RtwoE,\EtwoR\}.
\label{eq:directional}
\end{equation}
R2E 主要由 reaction-side gate 与自己的 expert mass 决定；E2R 主要由 protein-side gate 与另一 expert mass 决定。因此当前模型不要求
\begin{equation}
S_{\RtwoE}(r,e)=S_{\EtwoR}(r,e)
\end{equation}
逐点成立。

\section{Directional discrepancy bound}

\begin{theorem}[Partition--range discrepancy bound]
给定同一 active chart-score vector $k=(k_1,\ldots,k_m)$ 与两个合法 partitions $p,q$，定义
\begin{equation}
S_p=\sum_i p_ik_i,
\qquad
S_q=\sum_i q_ik_i.
\end{equation}
则
\begin{equation}
\abs{S_p-S_q}
\le
\frac12\norm{p-q}_1
(k_{\max}-k_{\min}).
\label{eq:direction-bound}
\end{equation}
\end{theorem}

\begin{proof}
因为 $\sum_i(p_i-q_i)=0$，对任意常数 $c$，
\begin{equation}
S_p-S_q=\sum_i(p_i-q_i)(k_i-c).
\end{equation}
取中点 $c=(k_{\max}+k_{\min})/2$，则
\begin{equation}
\abs{k_i-c}\le\frac{k_{\max}-k_{\min}}{2}.
\end{equation}
由三角不等式，
\begin{align}
\abs{S_p-S_q}
&\le\sum_i\abs{p_i-q_i}\abs{k_i-c}\\
&\le\frac{k_{\max}-k_{\min}}2\sum_i\abs{p_i-q_i},
\end{align}
即式 \eqref{eq:direction-bound}。
\end{proof}

\begin{corollary}
若 $p=q$，或所有 active charts 给出相同 scalar score，则两个 readouts 必然相同。
\end{corollary}

这个定理把“方向差异”拆成两部分：\textbf{partition mismatch} 与 \textbf{chart disagreement}。因此 overlap consistency 不仅提高局部语义一致性，也会压缩不同 directional partitions 能造成的最大 score 分歧。

\begin{remark}[为什么不立即强制 pair-aware partition]
形式更对称不等于 empirical risk 更低。历史 geometry 已经出现过“数学上更统一但 retrieval 退化”的情况，因此 pair-aware $\rho_\alpha(r,e)$ 应作为可验证新假设，而不是仅凭审美替换 frozen directional realization。
\end{remark}

\chapter{Chart Overlap 与 Gluing Consistency}

\section{加权一致性损失}

对一个 pair，定义
\begin{equation}
\mathcal L_{\mathrm{glue}}
=
\sum_{\alpha<\beta}
\rho_\alpha\rho_\beta
(K_\alpha-K_\beta)^2.
\label{eq:glue-loss}
\end{equation}
只有两个 chart 同时可用且都获得正 partition mass 时，它们的 disagreement 才被惩罚。

\begin{proposition}[非负性]
$\mathcal L_{\mathrm{glue}}\ge0$。
\end{proposition}
\begin{proof}
每一项均为两个非负权重与平方项的乘积。
\end{proof}

\section{Overlap graph 上的零损失条件}

对固定 pair 构造图 $G_{r,e}$：节点为 active charts；当且仅当 $\rho_\alpha\rho_\beta>0$ 时在 $\alpha,\beta$ 之间连边。

\begin{theorem}[零 gluing loss 的图论刻画]
对固定 pair，式 \eqref{eq:glue-loss} 为 0，当且仅当 $K_\alpha=K_\beta$ 对 $G_{r,e}$ 的每一条边成立。等价地，$K$ 在图的每个 connected component 上为常数。若 active overlap graph 连通，则所有 active chart scores 相等。
\end{theorem}

\begin{proof}
损失是有限个非负项之和，因此和为 0 当且仅当每个正权边对应的平方差为 0，即每条边两端 score 相等。沿任意连通路径反复应用等式，可知同一连通分量内全部节点相等。反向显然。
\end{proof}

\begin{remark}
该定理并不要求不同 latent representations isometric。Gluing 约束的是 scalar interaction，不是要求 sequence、structure、pocket 的坐标轴变成同一种几何。
\end{remark}

\chapter{局部低秩结构与双塔的数学理由}

\section{Hilbert--Schmidt 分解}

在一个固定 chart 上，假设 $K_\alpha$ 关于对应测度平方可积，使其定义一个 Hilbert--Schmidt integral operator。则存在 singular system
\begin{equation}
K_\alpha(r,e)=\sum_{j\ge1}\sigma_{\alpha j}
\nu_{\alpha j}(r)v_{\alpha j}(e),
\end{equation}
其中 $\sigma_{\alpha1}\ge\sigma_{\alpha2}\ge\cdots\ge0$。

取前 $d$ 项得到
\begin{equation}
K_{\alpha,d}(r,e)=
\sum_{j=1}^{d}\sigma_{\alpha j}
\nu_{\alpha j}(r)v_{\alpha j}(e).
\end{equation}

\begin{theorem}[截断误差]
Hilbert--Schmidt norm 下，
\begin{equation}
\norm{K_\alpha-K_{\alpha,d}}_{HS}^2
=\sum_{j>d}\sigma_{\alpha j}^2.
\end{equation}
而 rank-$d$ truncated singular expansion 是相应最优有限秩近似之一。
\end{theorem}

\begin{proof}
Hilbert--Schmidt singular functions 构成正交展开；Parseval identity 给出误差平方等于被截断 singular values 的平方和。最优性是 compact-operator 版本的 Eckart--Young 型结论。
\end{proof}

\section{双塔不是“必须共享 embedding space”}

若定义
\begin{equation}
\phi_\alpha(r)=
(\sqrt{\sigma_1}\nu_1(r),\ldots,\sqrt{\sigma_d}\nu_d(r)),
\end{equation}
\begin{equation}
\psi_\alpha(e)=
(\sqrt{\sigma_1}v_1(e),\ldots,\sqrt{\sigma_d}v_d(e)),
\end{equation}
则 $K_{\alpha,d}=\phi_\alpha^\top\psi_\alpha$。更一般地允许矩形 $G_\alpha$，reaction/enzyme coordinates 可以不同维。

因此 dual tower / local expert 可以理解为局部 interaction operator 的有限秩近似，而不是“生物学上 reaction 和 protein 天生属于同一个 Euclidean space”。

\begin{remark}
平方可积与低有效秩是建模假设/近似理由，不是从酶学第一原理推出的定律。模型是否足够低秩仍需 empirical validation。
\end{remark}

\chapter{Sparse Pair Supervision 与 Double-Unseen Prediction}

\section{pair labels 学什么，object observations 学什么}

FIBRE 把职责分开：

\begin{itemize}
  \item unpaired molecular observations 建立 $\phi_\alpha,\psi_\alpha$ 的坐标信息；
  \item sparse verified pairs 学习或校准 $G_\alpha$、chart applicability、overlap agreement 与 ranking/calibration；
  \item unknown pair 不自动提供 negative label。
\end{itemize}

这比“用 24 万已知 pair 从零生成所有 molecular representations”更符合数据事实。

\begin{theorem}[Double-unseen scoreability]
假设 universal chart 的 reaction/enzyme coordinate maps 是 raw molecular input 的函数，且对所有 valid inputs 定义。则一个训练中从未出现的 reaction $r^*$ 与一个训练中从未出现的 enzyme $e^*$ 的 pair 仍可获得至少一个局部 score，并经 partition 得到 retrieval readout。
\end{theorem}

\begin{proof}
$r^*,e^*$ 的 entity ID 是否出现不影响 raw-input coordinate maps 的定义。Universal chart 对 pair $(r^*,e^*)$ available，因此可计算 $K_0(r^*,e^*)$；由 universal coverage theorem，partition 可归一化并得到 readout。
\end{proof}

\begin{remark}
“可打分”不等于“保证准确”。Double-unseen performance 必须由 strict double-cold / temporal evaluation 另行证明。
\end{remark}

\chapter{Train-Free 的有限秩实验更新}

\section{Chart-local empirical interaction update}

对已接受的实验 observations
\begin{equation}
\Omega=\{(r_i,e_i,w_i)\}_{i=1}^{n},
\end{equation}
定义 chart $\alpha$ 上的有效权重
\begin{equation}
\eta_{i\alpha}=w_i\rho_\alpha(r_i,e_i),
\end{equation}
以及有限秩 update
\begin{equation}
\Delta_\alpha
=
\sum_{i=1}^{n}\eta_{i\alpha}
\phi_\alpha(r_i)\psi_\alpha(e_i)^\top.
\label{eq:finite-update}
\end{equation}
更新后的 local interaction form 为 $G_\alpha+\Delta_\alpha$。

\begin{theorem}[Rank bound]
式 \eqref{eq:finite-update} 满足
\begin{equation}
\operatorname{rank}(\Delta_\alpha)\le n.
\end{equation}
更精确地，不超过具有非零 $\eta_{i\alpha}$ 的 observation 数。
\end{theorem}

\begin{proof}
每个 outer product $\phi_i\psi_i^\top$ 的 rank 至多为 1；矩阵 rank 的次可加性给出
\begin{equation}
\operatorname{rank}\left(\sum_i M_i\right)
\le\sum_i\operatorname{rank}(M_i)\le n.
\end{equation}
\end{proof}

\section{Frobenius budget 与单 pair 扰动上界}

实现中把 raw update 统一 rescale，使
\begin{equation}
\norm{\Delta_\alpha}_F\le\varepsilon_\alpha.
\end{equation}

\begin{theorem}[Unit-coordinate score perturbation bound]
若 $\norm{\phi_\alpha(r)}_2\le1$、$\norm{\psi_\alpha(e)}_2\le1$，则
\begin{equation}
\abs{\phi_\alpha(r)^\top\Delta_\alpha\psi_\alpha(e)}
\le\varepsilon_\alpha.
\end{equation}
\end{theorem}

\begin{proof}
由 operator norm 与 Cauchy--Schwarz，
\begin{align}
\abs{\phi^\top\Delta\psi}
&\le\norm{\phi}_2\norm{\Delta}_2\norm{\psi}_2\\
&\le\norm{\Delta}_2\\
&\le\norm{\Delta}_F\\
&\le\varepsilon.
\end{align}
\end{proof}

因此新实验可以改变 ranking，但其单次 chart-local 作用幅度有可声明的数学预算，而不是无限制覆盖 base model。

\section{当前实现边界}

\texttt{FiniteRankInteractionUpdate} 已支持 reaction/enzyme coordinate widths 不同的矩形 $\Delta$；历史 \texttt{PositivePairConditioner} 是共享 square latent space 的特例。给 weights 直接传入 $w_i\rho_\alpha$ 即实现 chart-local statistic。

但是“自动识别一个外部 assay、解析实体、决定所有 applicable charts、生成各 chart coordinates、执行 update、做 calibration/evaluation”仍属于 application orchestration。Kernel primitive 的存在不能被扩写成这条完整流水线已经端到端验证。

\chapter{TPS Family Chart 与 Specialization 的一般形式}

\section{Family chart 不等于 dataset subset}

令 $U_{\mathrm{TPS}}\subset\Rset\times\Eset$ 表示 TPS-relevant biochemical regime。它的 applicability 应由 family/motif/sequence state、precursor/reaction chemistry 等 molecular evidence 决定，而不是“这个 ID 是否来自 MARTS”。

这一区分允许 TPS chart 在 185,918-protein general universe 内发挥作用，同时不删除 non-TPS candidates。Universal chart 始终覆盖所有 valid candidates。

\begin{proposition}[Specialist 不缩小搜索空间]
若 candidate universe 由任务层独立声明，且 specialist chart 只通过 partition mass 影响 score，而不改变 candidate set，则 specialist chart 的加入不能因其 unavailable 而移除 candidate。
\end{proposition}

\begin{proof}
Candidate membership 在 score computation 之前固定；unavailable specialist 仅令对应 partition mass 为 0。Universal chart 保证 score 仍定义，因此 candidate 保留。
\end{proof}

这一性质把早期“TPS candidate reservoir”与最终“TPS local chart”从数学上区分开。

\chapter{历史 Product-Manifold Geometry：为什么重要，又为什么被替代}

\section{旧模型的核心构造}

旧理论先构造 reaction manifold $M_R$ 与 enzyme manifold $M_E$，product metric 为
\begin{equation}
d_M((r,e),(r',e'))^2=d_R(r,r')^2+d_E(e,e')^2.
\end{equation}
对 known-positive support $\Omega=\{(r_i,e_i)\}$ 定义
\begin{equation}
J_\Omega(r,e)=\min_i
\left[d_R(r,r_i)^2+d_E(e,e_i)^2\right],
\end{equation}
\begin{equation}
m_R(r)=\min_i d_R(r,r_i)^2,
\qquad
m_E(e)=\min_i d_E(e,e_i)^2,
\end{equation}
以及 correspondence defect
\begin{equation}
\Delta_\Omega(r,e)=J_\Omega(r,e)-m_R(r)-m_E(e).
\end{equation}

\begin{proposition}[Correspondence defect 非负]
对任意 $(r,e)$，$\Delta_\Omega(r,e)\ge0$。
\end{proposition}

\begin{proof}
对每个 $i$，有
\begin{equation}
d_R(r,r_i)^2\ge m_R(r),
\qquad
d_E(e,e_i)^2\ge m_E(e).
\end{equation}
故每个 joint sum 都至少为 $m_R+m_E$；对 $i$ 取最小仍成立。
\end{proof}

$\Delta$ 的解释很吸引人：reaction 与 enzyme 可以各自接近某些已知对象，但只有同一个 positive precedent 能同时解释两边时 defect 才小。

\section{旧模型带来的正确洞见}

这段历史保留下来四个重要原则：

\begin{enumerate}
  \item pair relation 是核心科学对象，而不是两个独立 classifier 的偶然相遇；
  \item unknown 不等于 negative；
  \item 新 positive observation 可以对 relation field 做 train-free update；
  \item R2E 与 E2R 在生物层面应当指向同一 pair relation，而不是两个互不相干任务。
\end{enumerate}

\section{为何 global factor geometry 假设过强}

它失败的不是数学自洽，而是建模假设过强。

\subsection{Reaction-center tangent 的反例}
即使只在 base graph edge 上加入局部 tangent refinement、不增加 long edge、不删除 base edge、missing neutral，E2R MRR 仍出现明显退化。这说明 reaction-center observation 不应被迫成为 global reaction distance 的统一修正。

\subsection{Pocket coverage 的反例}
当时约 185,918 proteins 中 materialized pocket 仅约 1,287（约 0.69\%）。多数 local protein neighborhood 根本没有足够 pocket nodes；“一个 global structural metric”在大多数地方没有观测基础。

\subsection{Directional sections 的一致性问题}
理论上想要一个 field $F(r,e)$，但分别求得的 query-centered R2E/E2R sections 若 overlap 不一致，就不能仅凭命名说它们是同一 field restrictions。旧文档正是因此提出 partition-of-unity gluing。

\section{从 product manifold 到 interaction atlas 的逻辑}

最终不是放弃 geometry，而是\textbf{弱化全局假设}：

\begin{center}
全局 factor manifolds
$\longrightarrow$
局部 biochemical/information coordinate charts
$\longrightarrow$
局部 scalar interactions
$\longrightarrow$
partition-of-unity gluing.
\end{center}

换言之，atlas 保留“局部坐标 + overlap compatibility”的几何思想，同时允许每个 chart 使用不同 representation、维度和 availability domain。

\chapter{解释性、置信度与 Claim Boundaries}

\section{应当输出什么解释}

一个 atlas prediction 最自然的解释不是“某个 latent dimension 代表什么”，而是：

\begin{itemize}
  \item 哪些 charts available；
  \item 每个 chart 的 partition mass；
  \item 每个 local $K_\alpha$；
  \item 哪些 molecular views 缺失；
  \item charts 在 overlap 上是否 agreement；
  \item 哪些 external/experimental evidence 支持或限制解释。
\end{itemize}

这类解释与数学 decomposition 一致，不需要假设 latent axis 有人工可读标签。

\section{score 不自动等于概率}

只有当 calibration population、candidate universe、方向与 protocol 匹配时，才可以输出 probability-like confidence。否则应分开报告 score、rank、chart agreement、view coverage 与 provenance。

\section{negative observation 的作用域}

一个在条件 $c_0$ 下的 inactive assay 只证明 $A(r,e;c_0)$ 在相应 endpoint 下不支持活性；它不能无条件升级成 $\Kstar(r,e)$ 的永久 global negative。未来 context-aware model 应保留该条件标签。

% -----------------------------------------------------------------------------
\chapter{模型局限与下一步可证伪问题}

\section{Context 仍未被显式建模成第三因子}

当前 $\Kstar(r,e)$ 是 task-level projection。若未来有足够 dense condition observations，应研究 $K(r,e,c)$ 或 context-indexed charts，而不是继续把所有 assay 差异藏在噪声里。

\section{Pair-aware partition 尚不是 frozen production invariant}

当前方向化 partitions 是有意保留的工程现实。未来可测试 pair-aware $\rho_\alpha(r,e)$ 是否：

\begin{enumerate}
  \item 降低 R2E/E2R discrepancy；
  \item 不损害各自 ranking risk；
  \item 在 missing-modality 下保持 exact fallback；
  \item 不增加不可接受的计算成本。
\end{enumerate}

形式对称不是足够理由。

\section{Chart applicability 需要更强的生化监督}

当前 gates 很大程度来自历史 multi-expert routing。最终理想状态应让 family/mechanism/structure applicability 更直接地由可审计 molecular evidence 定义，并验证 calibration。

\section{Train-free update 的 orchestration 还需端到端验证}

Kernel 已证明并实现有限秩 update；下一步要验证“实验记录 → identity resolution → context/provenance → applicable charts → coordinate projection → bounded update → post-update evaluation”的完整闭环。

\section{结构/pocket coverage 仍然稀疏}

Atlas 解决的是 missingness 语义，不是凭空补全结构。Structure chart 的科学价值必须同时报告 coverage；coverage 增加后也需要重新评估它与 universal chart 的 overlap consistency。

\section{低秩假设需要持续 empirical audit}

局部低秩提供 dual-tower 的数学理由，但若某个 biochemical regime 的 singular spectrum 衰减很慢，就可能需要更高 rank、nonlinear local interaction 或新的 chart decomposition。

\chapter{总结：FIBRE 的最小数学核心}

如果把全部工程细节剥离，FIBRE 可以压缩为以下六条：

\begin{enumerate}
  \item 真实 activity 是 $A(r,e;c)$；当前 retrieval target 是受限任务下的 $\Kstar(r,e)$。
  \item 不同 molecular views 定义不同 local charts，而不是一个必须共享的 global metric。
  \item 每个 chart 用 $K_\alpha=\phi_\alpha^\top G_\alpha\psi_\alpha$ 表示局部 reaction-demand / enzyme-capability interaction。
  \item availability-aware partition of unity 把 local scalar estimates glue 成 retrieval readout；missing chart 为 zero mass，不是 zero biology。
  \item overlap consistency 约束同时适用的 charts 对同一 working compatibility 达成 scalar agreement，但不要求 latent coordinates 相同。
  \item sparse verified observations 可以形成有 rank 与 norm 保证的 bounded finite-rank interaction update，而不需要重训 molecular encoders。
\end{enumerate}

这六条共同回答了项目历史中反复出现的矛盾：既要 universal coverage，又要 local specialization；既要 rich representations，又不能强迫所有 views 全局齐次；既要双向 retrieval，又不能虚构当前工程 readouts 完全相同；既要吸收实验反馈，又要控制它对既有模型的扰动。

\chapter{两个核心算法的伪代码}

\section*{算法 A：Availability-aware atlas readout}
\begin{enumerate}
  \item 对输入 $(r,e)$，运行 universal raw-input encoders。
  \item 检查每个 optional chart 所需 molecular views 是否 available；不可用 chart 标记 $a_\alpha=0$。
  \item 对 available charts 计算 local coordinates 与 $K_\alpha$。
  \item 计算 applicability logits $q_\alpha$。
  \item 用 masked softmax 归一化 $\rho_\alpha$；unavailable chart exact zero。
  \item 输出 $\sum_\alpha\rho_\alpha K_\alpha$；训练时可同时计算 overlap consistency。
\end{enumerate}

\section*{算法 B：Bounded finite-rank observation update}
\begin{enumerate}
  \item 接受经过 provenance/identity/context 检查的新 pair observations。
  \item 在目标 chart 中计算 $\phi_\alpha(r_i),\psi_\alpha(e_i)$ 与有效权重 $\eta_{i\alpha}$。
  \item 形成 raw outer-product sum $\Delta_{raw}=\sum_i\eta_{i\alpha}\phi_i\psi_i^\top$。
  \item 若 $\norm{\Delta_{raw}}_F>\varepsilon$，整体缩放到 Frobenius budget $\varepsilon$。
  \item 使用 $G_\alpha+\Delta_\alpha$ 计算后续 local interaction。
  \item 保留 observation provenance，并在匹配 protocol 下重新评估 ranking/calibration。
\end{enumerate}
