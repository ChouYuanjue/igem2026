# Clean-only strongest system vs EnzymeCAGE

This snapshot excludes retention, association-visible, or otherwise exposure-driven results from clean generalization claims. `R2E` = reaction -> enzyme; `E2R` = enzyme -> reaction. Repository metric definitions are authoritative: Hit/SR@K, MRR, MAP, NDCG and AUROC must be interpreted under an explicitly fixed candidate support and information boundary, and a single Hit@K number is not sufficient to promote a method.

## Evidence hierarchy for EnzymeCAGE

1. **Primary reproducible comparison:** a locally executed EnzymeCAGE run on a support that can be reconstructed exactly, compared with frozen Catalyst on that exact same support and denominator.
2. **Secondary local evidence:** real EnzymeCAGE score unions or partial reconstructions whose support differs from the current Catalyst benchmark; useful for capability/provenance, but not for raw cross-support deltas.
3. **Paper-reported values:** context for the original paper only. They are explicitly not a local rerun and must not be described as “our reproduced EnzymeCAGE result.”
4. Missing CAGE metrics are N/A; they are never imputed from Catalyst, from unsupported pairs, or from paper-level aggregate numbers.

## Top-2000 reranker / router: current internal confirmation

The original unrestricted pair-head V1 regressed badly and is rejected. The bounded residual V2 froze `residual_scale=0.03` using only internal folds 0/1/2, then passed a previously unseen fold3 confirmation. On fold3, coarse -> reranked changed MRR **0.10805 -> 0.11384**, MAP **0.08561 -> 0.09117**, NDCG@10 **0.10784 -> 0.11868**, Hit@10 **24.64% -> 27.68%**, while Hit@20 **33.36% -> 33.65%** and Hit@50 **41.42% -> 41.52%** did not regress; median best-positive rank improved **130 -> 105**.

A label-free difficulty router then froze the rule `use residual 0.03 iff max_train_drfp_tanimoto >= 0.9; otherwise exact coarse fallback` and passed a fresh salted strict double-cold fold6. There, MRR **0.10205 -> 0.11484**, MAP **0.08246 -> 0.09764**, NDCG@10 **0.10805 -> 0.12283**, Hit@10 **24.19% -> 25.95%**, Hit@20 **31.23% -> 33.43%**, Hit@50 **41.64% -> 44.43%**, and median best-positive rank **137 -> 90.5**. The `<0.3` reaction-similarity regime still receives the exact coarse fallback and remains a capability gap rather than being hidden by aggregate gains.

These are internal clean confirmations, not authorization to reuse an already revealed outer set. A future unbiased external claim requires a genuinely fresh frozen benchmark or a separately preregistered evaluation path.

## Reaction-center residual: internally confirmed low-similarity capability

The mapped reaction-center signal was then revisited without reinitializing the proven RDKit+ towers. `IdentityHiddenResidualReactionDualTower` keeps the base protein tower and base 3139-d RDKit+ reaction tower frozen, starts from an exactly zero residual (`max_abs_diff = 0.0` before training), and trains only `aux_to_hidden.weight` from the fixed 1280-d reaction-center block. The development protocol contained one candidate and no hyperparameter sweep.

Across the preregistered clean folds 0/1/2, all 3,226 R2E queries improved from MRR **0.09861 -> 0.10862**, MAP **0.08257 -> 0.08999**, NDCG@10 **0.10542 -> 0.11573**, and Hit@10/20/50 each by **+2.51 pp**; median best-positive rank improved **149 -> 107**. More importantly, the pooled 204-query `<0.3` reaction-similarity slice improved MRR **0.02867 -> 0.03382**, MAP **0.02170 -> 0.02503**, AUROC **0.90226 -> 0.90694**, NDCG@10 **0.03362 -> 0.03677**, Hit@10 **9.80% -> 10.29%**, with Hit@50 unchanged and median rank **1436.5 -> 1344**. Hard-slice MRR and MAP improved on all three folds.

A completely fresh salted strict double-cold confirmation (`r2e_center_residual_v2_confirm_20260831`, fold4) then passed every frozen gate. On all 1,155 queries, MRR **0.10851 -> 0.11501**, MAP **0.09084 -> 0.09688**, NDCG@10 **0.11595 -> 0.12420**, Hit@10 **26.32% -> 27.97%**, Hit@20 **32.21% -> 35.41%**, Hit@50 **40.43% -> 43.98%**, median rank **123 -> 90**. On its 57 `<0.3` queries, MRR **0.05839 -> 0.06286**, MAP **0.04265 -> 0.04711**, NDCG@10 **0.05973 -> 0.06744**, Hit@10 **15.79% -> 17.54%**, Hit@20 **21.05% -> 22.81%**, Hit@50 stayed **24.56%**, and median rank improved **828 -> 786**. This promotes the residual as an **internally confirmed** low-similarity R2E representation, not as an externally confirmed model. A post-hoc 10,000-replicate paired bootstrap supports strong aggregate improvement, while the 57-query `<0.3` MRR/MAP intervals still cross zero, so hard-slice statistical certainty must not be overstated.

A genuinely fresh source-snapshot external protocol has therefore been frozen before reveal: Rhea release 128 (2023-07-12) -> release 141 (2026-06-10), using direction-specific `RHEA_ID`, the same unambiguous protein-alias mapping that exactly reconstructs all 218,537 clean2023 pairs from the 307,027-row compact 2023 source, performance-blind Swiss-Prot association deltas, and the unchanged 185,918-protein candidate support. An earlier MASTER_ID/exact-protein V1 was invalidated by this provenance audit before release141 associations were extracted or any target model score was read. The protocol requires at least 50 eligible reaction queries and 200 test pairs; otherwise it is reported as underpowered rather than relaxed. It is a fresh **association-label snapshot delta under a candidate/feature universe frozen before reveal**, not a claim that the entire deployment environment is historically frozen to 2023. No Rhea128->141 model performance may be used to modify the residual or benchmark definition.

## Current improvement target

Extreme reaction novelty is **no longer an exact-fallback-only regime**: the reaction-center residual has produced reproducible internal gains in `<0.3`, while the Top-2000 pair router remains a complementary high-similarity (`>=0.9`) expert. The unresolved question is now whether the low-similarity gain survives a genuinely fresh source-snapshot external benchmark with adequate support. Difficulty/capability reporting must continue to expose slice sizes and uncertainty rather than collapsing the story into aggregate MRR. Enzyme-405 and all previously revealed temporal/ReactZyme cells remain confirmatory/descriptive and must not be reused for iterative model selection.
