# BRIDGE reproducibility map

This directory is the current claim-facing namespace for BRIDGE.

The experiments that produced the current numbers were executed before the final method name was frozen, so several immutable result files still carry `FIBRE_*` filenames. `canonical.json` maps current BRIDGE claims to those exact historical files without rewriting them.

New BRIDGE experiments should write new BRIDGE-named records here. Historical FIBRE method source is archived at `archive/fibre/20261003/`.
