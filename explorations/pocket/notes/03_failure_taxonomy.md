# Failure Taxonomy

Initial taxonomy for manual analysis of EnzymeCAGE or pocket-intervention
failure cases:

- wrong pocket hypothesis
- reaction center uncertainty
- candidate pool recall failure
- missing cofactor evidence
- missing catalytic residue evidence
- enzyme family mismatch
- possible false negative label
- multiple plausible enzymes or promiscuity

Each failure case should eventually record the reaction, enzyme, baseline score,
new score, pocket evidence, and a short human-readable reason.
