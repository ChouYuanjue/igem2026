# FIBRE historical snapshot — 2026-10-03

This directory freezes the retired **FIBRE — Factorized Interaction Basis for Reaction–Enzyme** line at the point where the active method moved to **BRIDGE — Broad Retrieval with Inference-Driven Gated Experts**.

FIBRE explored interaction-atlas geometry, conditional catalytic modes, a relational core, scientific-evidence anchoring, and plug-in expert routing. These experiments remain development evidence, but the interaction-atlas / unified-relational-core formulation is no longer the current ranking method.

The surviving design conclusions are now expressed by BRIDGE: keep a strong Broad base order; treat optional evidence as missing-neutral; decide expert applicability per query and direction; allow only bounded corrections; and retain family specialists only where they demonstrate local value.

- `implementation/` — complete tracked FIBRE source snapshot.
- `tooling/` — exact pre-migration FIBRE workflow/release entrypoints.
- `reproducibility/` — narrative/theory selection records moved out of the active reproduction surface.
- immutable FIBRE-named JSON results remain under `reproducibility/bime_rank/records/` because their historical filenames and hashes are part of provenance.
