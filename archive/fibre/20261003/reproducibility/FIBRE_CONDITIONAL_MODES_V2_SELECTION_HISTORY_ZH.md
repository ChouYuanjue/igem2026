# FIBRE 条件催化模式第二版：数学候选选择记录

## 1. 目标

这一轮修改针对第一版数学解释与实际计算图之间的脱节。核心问题有三个：

1. 第一版把不同专家视为需要在重叠区域估计同一个局部标量，因此加入 0.02 跨专家一致性惩罚；
2. 真实模型的两个方向依赖不同查询侧门控，强迫它们压成一个完全对称的配对分数会损失任务信息；
3. 用户允许很小的指标交换，前提是数学结构明显更自然、可解释、可继续扩展。

## 2. 第一轮探索：完全对称联合势

尝试让反应侧门控与蛋白侧门控先形成共同专家分布，再对同一配对只输出一个联合分数。

研究过：

- 双侧门控几何平均；
- 对称线性专家混合；
- Gibbs 型对数配分聚合；
- 门控熵决定权重的信息量加权 KL 重心；
- 分子一体势补偿方向差异。

这些方案的共同问题是：酶找反应的部分指标可以改善，反应找酶的早期排序通常明显下降。实验说明两个检索方向包含真实的条件信息，强行把最终读出压成一个方向无关标量会丢失有用结构。

## 3. 第二轮探索：专家分歧直接控制回退

尝试把专家分数方差作为逐配对不确定性，并用 \(1-\operatorname{Var}\) 自动缩小专家修正强度。

该方案的动机来自余弦分数范围 \([-1,1]\)，方差具有天然上界，不需要额外调参。

开发实验仍显示反应找酶明显下降，因此没有进入冻结确认。

## 4. 第三轮探索：规范化条件专家混合

把每个专家先在候选轴上归一化成条件分布：

\[
p_k(e\mid r)=
\frac{\exp(s_k(r,e)/\tau)}
{\sum_{e'}\exp(s_k(r,e')/\tau)},
\]

再由查询侧门控混合。

这个方案解决了“不同专家原始分数零点和尺度未必可直接比较”的数学问题，但在公平同初始化开发实验中，反应找酶 MRR 降到约 0.03787，明显弱于基准约 0.05027，因此直接否决。

## 5. 一次重要的实验纠错

早期探索脚本为了测试分子一体势，临时在两座编码塔末尾增加了额外线性头。后续某些方案虽然没有使用这个头，但模型构造过程已经额外消耗随机数，使后构造的反应塔初始化发生变化。

因此早期几组细小差异不能作为正式方法比较。

发现这一问题后，实验脚本重新从冻结评测器复制，只保留不增加任何参数的聚合分支，确保：

- 模块构造顺序一致；
- 随机数消耗一致；
- 输入一致；
- 网络宽度一致；
- 随机种子一致；
- 训练目标一致。

正式选择只使用这次公平重跑。

## 6. 公平开发候选

九个开发格比较四组：

### 第一版基准

跨专家一致性权重 0.02。

### 候选 A：直接删除一致性项

一致性权重 0。

开发结果：

- 反应找酶 MRR：0.05027 → 0.05165；
- 反应找酶 Hit@3：4.12% → 4.94%；
- 反应找酶 Hit@10：保持 9.88%；
- 反应找酶 Hit@20：18.11% → 18.52%；
- 酶找反应 MRR：0.05760 → 0.05687；
- 酶找反应 Hit@10：14.73% → 13.85%；
- 酶找反应 Hit@3 与 Hit@20 略有提高。

该候选删除一个经验常数和一个额外“专家应该数值一致”的假设，因此在查看冻结格前被选定。

### 候选 B：规范化条件概率混合

酶找反应部分早期指标提高，反应找酶 MRR 约 0.03787，未晋级。

### 候选 C：按专家维度缩放一致性

取 \(1/(2d)=1/64=0.015625\)，希望让正则尺度由 32 维专家几何给出。

结果接近第一版 0.02，同时没有给出优于直接删除的一致结构，因此未晋级。

## 7. 单次冻结确认

候选 A 锁定后查看十六个冻结格。

冻结结果：

- 酶找反应 MRR：0.08002 → 0.08080；
- 酶找反应 Hit@3：7.98% → 8.09%；
- 酶找反应 Hit@5：13.06% → 13.41%；
- 酶找反应 Hit@10：21.27% → 21.04%；
- 酶找反应 Hit@20：32.95% → 32.83%；
- 反应找酶 MRR：0.04212 → 0.04246；
- 反应找酶 Hit@5：4.46% → 4.67%；
- 反应找酶 Hit@10：11.25% → 11.46%；
- 反应找酶 Hit@20：19.53% → 19.75%。

10,000 次成对查询格自助法中，多数差异的 95% 区间跨零。第二版因此强调“结构简化且性能保持”，不宣称小差异显著。

## 8. 完整协议与广域复核

候选确认后补跑完整协议。

- 中位最佳阳性：29 → 28；
- Hit@3/5/10/20 全部提高。

完整 25 格严格双冷反应找酶：

## 9. 最终数学选择

第二版保留原方向条件线性期望，因为它与实际任务和冻结代码都最一致：

\[
S_{R\to E}
=(1-\mu_R)s_0+\mu_R\sum_kq^R_ks_k,
\]

\[
S_{E\to R}
=(1-\mu_E)s_0+\mu_E\sum_kq^E_ks_k.
\]

新的理论贡献来自对这套计算图的重新组织：

- 一个通用交互块；
- 八个潜在催化模式块；
- 查询条件块对角正算子；
- 专家矛盾作为描述性不确定性保留；
- 跨专家一致性惩罚删除。

这条路线没有为了数学对称性牺牲真实检索方向，也没有继续依赖经验粘合常数。

## 10. 加权对数指数和聚合探针：开发可接受，冻结未通过

在第二版已经确定之后，我们额外测试了一个不增加参数的非线性聚合候选。它把九个现有分量的线性期望替换为

\[
S_{\mathrm{lse}}
=
\log\sum_k w_k\exp(s_k).
\]

输入、网络结构、随机数消耗、训练协议、专家数、专家维度和一致性权重全部保持第二版设置。

九个开发格中：

- 酶找反应 MRR：0.05687 → 0.05964；
- 酶找反应 Hit@3/5/10/20 均提高；
- 反应找酶 MRR：0.05165 → 0.05128；
- 反应找酶 Hit@3：4.94% → 4.12%；
- 反应找酶 Hit@10：9.88% → 11.11%；
- 反应找酶 Hit@20：18.52% → 18.11%。

因为酶找反应有较完整的提升、反应找酶只出现有限交换，这个候选在开发阶段获得一次冻结确认资格。

冻结十六格中：

- 酶找反应 MRR：0.08080 → 0.07945；
- 酶找反应 Hit@5：13.41% → 12.83%；
- 酶找反应 Hit@10：21.04% → 20.81%；
- 酶找反应 Hit@20：32.83% → 32.25%；
- 反应找酶 MRR：0.04246 → 0.04118；
- 反应找酶 Hit@3：2.55% → 2.97%；
- 反应找酶 Hit@10：11.46% → 10.40%；
- 反应找酶 Hit@20：19.75% → 18.68%。

候选因此不晋级，也没有在冻结结果揭示后继续调节指数尺度。

这项实验只说明：在当前无量纲专家分数上，直接使用加权对数指数和没有比第二版线性读出更稳定。它保留为非线性聚合负结果，不构成当前模型定义。

## 11. 二阶非线性聚合候选：开发阶段直接否决

为了测试更温和的非线性修正，又使用

\[
S^{(2)}
=
\bar s+\frac12V.
\]

这个实验不增加任何可训练参数，也不改变模型构造或随机初始化。

九个开发格中，酶找反应 MRR 从 0.05687 提高到 0.05967，多个前若干命中同时提高；反应找酶 MRR 从 0.05165 降到 0.04661，Hit@3、Hit@10、Hit@20 也出现回退。按照预先使用的多指标晋级纪律，该候选在开发阶段直接否决，没有查看冻结十六格。

结果说明把专家方差直接加入生产排序没有通过开发门槛。方差继续只作为模式分歧诊断量。完整记录见 FIBRE_SECOND_ORDER_SCORE_AGGREGATION_V1_RESULT.json。

## 12. 反应中心模式后验：解决方向污染，但冻结反应找酶未通过

为回应历史反应中心支线中“信息有价值、进入方式却反复造成掉点”的问题，本轮没有再把反应中心拼到全部反应表示、全局几何或配对分数上。

实验采用两阶段结构：

1. 按第二版协议训练基础八模式；
2. 冻结基础模型；
3. 用无偏置、零初始化的反应中心证据头产生 \(\ell_k^{RC}(r)\)；
4. 只在反应找酶方向更新模式先验
   \[
   q_k^{R,+}\propto q_k^{R,-}\exp(\ell_k^{RC});
   \]
5. 酶找反应路径完全不读取这个证据头。

这使酶找反应的全部指标在开发与冻结中都和第二版基线逐位一致。

九个开发格中：

- 反应找酶 MRR：0.05165 → 0.05252；
- Hit@5/10/20 保持不变；
- Hit@3：4.94% → 4.53%；
- 中位最佳阳性名次：140 → 146；
- 全反应平均模式后验相对基础门控的 KL 改变量约 0.0667。

因为反应找酶 MRR 提升、Hit@5/10/20 保持，同时酶找反应严格不变，该候选获得一次冻结确认资格。

冻结十六格中：

- 酶找反应所有指标严格不变；
- 反应找酶 MRR：0.04246 → 0.04179；
- Hit@3 与 Hit@5 保持不变；
- Hit@10：11.46% → 11.04%；
- Hit@20：19.75% → 19.32%；
- 中位名次：135 → 136。

因此该候选没有晋级，也没有在冻结结果揭示后调证据强度、正则或适用域阈值。

这次实验解决了一个明确的结构问题：反应中心只作用于反应侧模式权重时，酶找反应方向可以保持逐位不变。冻结反应找酶指标没有通过晋级门槛，因此该证据头没有进入当前冻结模型。完整记录见 FIBRE_REACTION_CENTER_MODE_EVIDENCE_V1_RESULT.json。
