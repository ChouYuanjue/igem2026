# FIBRE release and rebuild contract

FIBRE has three release profiles whose scientific claims are deliberately different.

## FIBRE Method Kit

Contains the current factorized-interaction definition, bounded interaction/update primitives, schemas and tests. It contains no project-trained weights and no current project database.

A transferable implementation must preserve the universal base prediction contract: reaction and enzyme raw inputs define the prediction domain; optional views cannot be mandatory eligibility gates.

## FIBRE Reproduction Bundle

Contains or content-addresses every frozen asset required by current benchmark claims. It may include project-trained weights only when a frozen claim requires them.

The reproduction bundle is the only source of benchmark-performance claims. It includes negative or mixed development results when they determine a promotion decision.

## Starase Application Bundle

May use all current accepted molecular observations, pair associations, family-specialized weights, evidence caches and live provenance-bound sources. It is allowed to be stronger and less isolated than the reproduction bundle.

Application results cannot be quoted as benchmark evidence.

## Positive observations

A verified new enzyme–reaction positive may be used in application inference through a bounded finite-rank interaction update. Promotion into a persistent data snapshot is a separate governance action. A frozen reproduction run never reads later application observations.

## Historical geometry assets

Legacy correspondence/manifold assets are retained only when needed for provenance, compatibility or frozen historical results. Their presence does not make them part of the current FIBRE method package.
