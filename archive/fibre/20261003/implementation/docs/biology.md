# Biological interpretation of the FIBRE interaction atlas

Catalysis is not controlled by one molecular descriptor. A reaction imposes several demands — bond reorganization, charge stabilization, geometry, proton/electron transfer, cofactor requirements and substrate organization — while an enzyme supplies capabilities through sequence, fold, pocket geometry, residues, electrostatics and dynamics.

FIBRE treats these observations as different local coordinate systems for the same task-level catalytic compatibility. Physical activity itself remains assay/context dependent.

A broad chart built from raw reaction chemistry and protein sequence is always available. More specific charts become informative when their biology is present: reaction-centre chemistry, structure/pocket context, mechanistic motifs, family state or verified pair context.

The charts are not separate biological tasks. Each estimates the same working compatibility for an enzyme–reaction pair. The current frozen system may use different R2E and E2R partitions over shared local chart scores; an ideal pair-aware atlas uses one pairwise partition. In either case, missing information is not converted into negative evidence.

This makes many-to-many catalysis natural. One enzyme can have high interaction under several reaction-demand charts, while unrelated sequences can occupy similar catalytic-capability coordinates inside a mechanistic chart.

TPS specialization is a family chart rather than a TPS dataset. Its support is defined by terpene-synthase biology and compatible chemistry. It can therefore improve TPS-relevant predictions in a large candidate universe without excluding non-TPS candidates from the global model.

Sparse verified enzyme–reaction pairs teach the local interaction forms and how charts overlap. Rich unpaired sequence, structure and chemistry information supplies the coordinates themselves.

New wet-lab observations admit bounded finite-rank chart-local interaction updates without retraining molecular encoders. The mathematical update primitive is implemented; automatic projection of every observation across all applicable charts is an application-layer step and is not implied merely by the kernel primitive.

FIBRE outputs remain predictions accompanied by their contributing charts and provenance-bound experimental/database evidence.
