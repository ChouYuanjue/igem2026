# FIBRE 当前状态

当前科学冻结版本是 **FIBRE-Modes**。这个状态页只列已经实现并完成评测的事实。

## 当前计算图

模型包含一个 128 维通用交互分量和八个 32 维局部模式分量。

反应找酶：

\[
S_{R\to E}
=
(1-\mu_R)s_0
+
\mu_R
\sum_{k=1}^{8}
q^R_k(r)s_k.
\]

酶找反应：

\[
S_{E\to R}
=
(1-\mu_E)s_0
+
\mu_E
\sum_{k=1}^{8}
q^E_k(e)s_k.
\]

FIBRE-Modes 保持 FIBRE-Atlas 的输入、网络宽度、八专家结构、双向多阳性排序目标和前三/前十/前二十边界目标，只删除跨专家分数一致性惩罚。

当前 \(\mu_R,\mu_E\) 仍是两个方向各自学习的标量。查询自适应总质量已经实际测试：双向端到端版本和 E2R-only 端到端版本都会通过共享训练明显伤害 R2E；随后冻结整个 v2 核心、只训练 513 参数的蛋白侧 E2R local-mass gate，R2E 可严格保持不变，但冻结 16 格中 E2R MRR 仅 0.08080 → 0.08120，主要 Top-K 提升约 0.23 个百分点，成对 bootstrap 区间大多跨零，同时最佳阳性名次略变差。因此该 gate 没有进入当前冻结读出。

## 科学证据扩展层

仓库已经实现冻结核心排序上的可插拔科学证据层。潜在催化模式仍属于 FIBRE-Modes 内部表示；外部结构、机制、分子视角和实验上下文通过独立证据接口接入。

当前接口要求每条证据提供候选级分数、可用性和可选的 0–1 质量量。证据缺失时贡献严格为零，不改变核心分数，也不重新分配其他证据的权重。每个模块的分数中心和尺度在准入训练期一次性冻结，运行时不因候选集合变化而重算。新证据的默认强度由内部交叉拟合的非负成对排序目标学习。

正式准入直接保护实验前缀：每个 held-out 折的成对逻辑损失都要下降，查询级成对增益 bootstrap 下界要为正，OOF MRR 增益的 95% bootstrap 下界也要为正，同时 Hit@3、Hit@10、Hit@20 的总体变化不能为负。多个证据同时参与同一排序时必须联合拟合；bundle 默认使用非负 L1 正则。

已经完成三类真实验证：

- CLIPZyme 结构证据通过当前 v4 排名准入：1,348 个可评测 OOF 查询的 MRR 平均增量 +0.02440，95% bootstrap [0.01176, 0.03755]；Hit@3/10/20 总体增量 +0.01409/+0.04154/+0.07418。此前严格时间 R2E 实验还得到 MRR 0.03626 → 0.06204。
- 已知阳性酶的历史专用上下文实验在 2,595 次交叉拟合试验中得到 MRR 0.13137 → 0.29881、Hit@10 29.83% → 63.35%，证明用户已有实验事实可以形成强条件证据。
- 反应中心残差的三个 held-out 折都降低成对逻辑损失，但 3,299 个 OOF 查询的 MRR 平均下降 0.04760，Hit@3/10/20 分别下降 0.08578/0.08700/0.05911。它现在归类为有信息的机制证据，不获得改变主排序的权限。

科学证据层因此区分“有信息”和“排序准入”。前者可以进入解释、诊断和结果展示；后者才允许改变候选顺序。多个准入证据同时进入同一排序时必须在同一冻结核心上联合交叉拟合；生产运行时拒绝直接叠加多个独立准入结果。准入系数同时绑定核心 baseline 标识。

## 反应中心模式证据实验

已经完成一个两阶段实验：

1. 训练 FIBRE-Modes 基础模型；
2. 冻结基础参数；
3. 反应中心特征训练零初始化、无偏置的八维证据头；
4. 只修改反应找酶方向的模式权重；
5. 酶找反应路径保持不变。

开发九格：

- 反应找酶平均倒数排名：0.05165 → 0.05252；
- 前五、前十、前二十保持；
- 前三：4.94% → 4.53%。

冻结十六格：

- 酶找反应全部指标逐位不变；
- 反应找酶平均倒数排名：0.04246 → 0.04179；
- 前三、前五保持；
- 前十、前二十各下降约 0.42 个百分点。

该候选没有晋级。FIBRE-Modes 冻结评分不使用反应中心证据头。

## 非线性聚合探针

对现有无量纲专家分数做过两类非线性聚合实验：

- 加权对数指数和；
- 线性均值加二分之一加权方差。

两者都没有通过晋级纪律。前者在一次冻结确认中回退；后者在开发格已经否决。

这些结果只作为已完成的负实验保留，不构成当前模型定义。

## 当前明确没有的内容

当前 FIBRE 没有：

- 用真实动力学常数训练的模型；
- 激活自由能预测；
- 催化常数或米氏常数预测；
- 热力学温度输入；
- 焦耳每摩尔或千焦每摩尔输出；
- 自动把任意湿实验写回生产模型的闭环。

文档不把这些内容写成当前能力。
